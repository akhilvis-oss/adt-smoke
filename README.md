# adt-smoke

Scratch repository for the [agentic-delivery-team](https://github.com/akhilvis-oss/agentic-delivery-team) lifecycle smoke test. A fixed, tiny story runs through the real lifecycle here, with the real coding agent, before framework changes are used. See `docs/design/safety-net.md` in the framework repository.

Everything here is throwaway. Issues and pull requests are opened and closed by the smoke test.
